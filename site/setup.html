One-time setup

Push keys

Generates the VAPID key pair for iOS notifications in your browser. Nothing is sent anywhere.

✅ Push is already configured

This site already has a public key. Only create new keys if you lost the private one, and re-enable notifications on each device afterwards.

1. Secret VAPID_PRIVATE_KEY

Keep this private. Don't paste it anywhere except the GitHub secret.

Open “New secret”
  1. Name: VAPID_PRIVATE_KEY
  2. Secret: paste the value above → Add secret

2. Variable VAPID_PUBLIC_KEY

Open “New variable”
  1. Name: VAPID_PUBLIC_KEY
  2. Value: paste the value above → Add variable

3. Redeploy

Open Actions → Stock check & deploy → Run workflow. Or just wait up to 5 minutes for the next scheduled run.

Then open Duo Stock from your Home Screen and tap Enable notifications.
